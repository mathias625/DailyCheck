# Daily Check

## Descrição do projeto
Projeto Full Stack chamado **Daily Check**, desenvolvido com Node.js, MySQL e Prisma no backend, com frontend em HTML, CSS e JavaScript.

O sistema permite gerenciar tarefas do dia a dia e consultar a temperatura de qualquer cidade em tempo real.

---

## Tecnologias

### Backend:
- Node.js
- Express
- Prisma
- MySQL

### Frontend:
- HTML
- CSS
- JavaScript

### Ferramentas:
- VS Code
- Insomnia
- MySQL

---

## Funcionalidades
- Criar tarefas
- Listar tarefas
- Atualizar tarefas
- Excluir tarefas
- Visualizar tarefas em cards na Home
- Buscar temperatura por cidade
- Exibir clima, temperatura, umidade e vento
